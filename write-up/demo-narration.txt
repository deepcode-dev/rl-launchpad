This demo shows a from-scratch PyTorch PPO policy for command-conditioned Unitree Go1 locomotion in MuJoCo Playground.

The actor receives a 48-value observation and outputs 12 normalized joint targets through a 512-256-128 SiLU MLP. A privileged 123-value critic is used only during training. PPO uses generalized advantage estimation, four minibatch passes, a clipped surrogate, Huber value loss, and entropy regularization.

Training keeps the stock task reward. The wrapper adds correct vector autoreset and termination handling, bounded actions, running observation normalization, and the declared 0.7/0.3 action filter. Evaluation is deterministic and uses the same command-tracking metric for both agents.

The final custom result uses five independent 200-million-step seeds: 9033, 9006, 9018, 9016, and 8009. Each reaches the 1,000-step horizon on all 50 fixed evaluation episodes. The aggregate return is 19.752 plus or minus 0.020, with linear velocity error 0.0851 meters per second.

The measured training curve comes from 244 logged points for every seed, sampled every five epochs. The chart compares this custom mean and standard deviation with the three-seed Brax reference.

The main limitation is speed: the custom run averages 13,561 seconds because data crosses the JAX-MJX and PyTorch boundary, while the documented Brax run takes 589 seconds. This is a simulation result only, with no sim-to-real claim. The footage uses only the reported 9033 checkpoint under three deterministic evaluation-style command vectors.
